# C3-World-Simulate-Game

自分で作ってみたくて作った、GitHubのIssueにコメントを書くとターンが進む陣取り・交易ゲームです。

1日4回、9時・13時・17時・21時までにコメントすれば、それを読み取って世界が自動で進みます（反映は締め切りから1時間ほど余裕を見てください）。放置していても最低限は成長するので、忙しいときは無理にコメントしなくても大丈夫です。

盤面はここでいつでも見られます。

**https://kya6-tomato.github.io/C3-World-Simulate-Game/**

---

## 遊び方

1. 自分専用のIssueを探す（無ければkya6に一声かけてください）
2. 今ターンにしたいことをコメントで書く。書き方は [コメントの書き方.md](コメントの書き方.md)
3. あとは待つだけです。次のターンで反映されて、結果もそのIssueに返信されます

資源の意味や行動の中身、信用のルールなどは [ルールブック.md](ルールブック.md) にまとめました。わからなくなったら見てください。

何もコメントしなくても、いつもの行動が自動で続くので、書き忘れても詰みません。気が向いたときにコメントしてもらえれば十分です。
